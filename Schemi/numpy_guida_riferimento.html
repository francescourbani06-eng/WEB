Creazione di array

Il punto di partenza di ogni script: costruire un array a partire da dati esistenti, oppure generarlo da zero con una forma e un contenuto scelti.

np.array(oggetto, dtype=None)
Converte una lista, tupla o sequenza annidata in un ndarray.
a = np.array([1, 2, 3])
b = np.array([[1, 2], [3, 4]])
# b.shape → (2, 2)
np.zeros(shape) / np.ones(shape)
Array pre-riempiti di zeri o di uno: comodi come contenitori iniziali.
np.zeros((2, 3))
# array([[0., 0., 0.],
#        [0., 0., 0.]])
np.full(shape, valore)
Array riempito con un valore costante a scelta.
np.full((2, 2), 7)
# array([[7, 7],
#        [7, 7]])
np.eye(n)
Matrice identità n×n, con 1 sulla diagonale principale.
np.eye(3)
# array([[1., 0., 0.],
#        [0., 1., 0.],
#        [0., 0., 1.]])
np.arange(inizio, fine, passo)
Sequenza con passo fisso, come range() ma restituisce un array.
np.arange(0, 10, 2)
# array([0, 2, 4, 6, 8])
np.linspace(inizio, fine, num)
num punti equidistanti tra inizio e fine, estremi inclusi.
np.linspace(0, 1, 5)
# array([0., 0.25, 0.5, 0.75, 1.])
np.empty(shape)
Alloca memoria senza inizializzarla: più veloce di zeros(), ma contiene valori casuali residui.
np.zeros_like(a)stessa forma e dtype di a, riempito di zeri (esistono anche ones_like e full_like)
a.copy()copia indipendente dei dati, non una vista
np.diag(v)crea una matrice diagonale da un vettore, o estrae la diagonale da una matrice
np.identity(n)equivalente a np.eye(n) senza offset
np.fromfunction(f, shape)costruisce un array applicando una funzione alle coordinate di ogni cella

Indicizzazione e slicing

Estrarre porzioni di dati è probabilmente l'operazione più frequente. NumPy estende lo slicing di Python a N dimensioni, e aggiunge indicizzazione booleana e fancy indexing.

a[inizio:fine:passo]
Slicing base, identico nella sintassi a quello delle liste Python.
a = np.arange(10)
a[2:7:2]   # array([2, 4, 6])
a[::-1]    # inverte l'array
m[righe, colonne]
Slicing multidimensionale: un indice o slice per ogni asse, separati da virgola.
m = np.arange(12).reshape(3, 4)
m[1, :]     # seconda riga
m[:, 2]     # terza colonna
m[:2, 1:3]  # sotto-blocco
a[condizione]
Indicizzazione booleana: seleziona solo gli elementi che soddisfano la condizione.
a[a > 5]
# solo i valori maggiori di 5
a[[i, j, k]]
Fancy indexing: seleziona elementi da una lista arbitraria di indici.
a[[0, 2, 4]]
# elementi agli indici 0, 2, 4
np.where(cond, x, y)
Restituisce x dove la condizione è vera, y altrove; senza x e y restituisce gli indici veri.
np.where(a > 5, a, 0)
# mantiene a dove > 5, azzera il resto
a.take(indici)come il fancy indexing, ma accetta anche un iterabile
np.select(cond, scelte)scelta multipla vettorizzata, l'equivalente di if/elif/elif...
a.diagonal()estrae la diagonale principale
np.compress(cond, a)filtra un array lungo un asse in base a una condizione

Manipolazione della forma

Cambiare la forma di un array non ne cambia i dati sottostanti: la maggior parte di queste funzioni restituisce una vista, non una copia.

a.reshape(nuova_forma)
Riorganizza gli elementi in una nuova forma con lo stesso numero totale di valori. Usa -1 per far calcolare una dimensione automaticamente.
np.arange(6).reshape(2, 3)
np.arange(6).reshape(-1, 1)
# -1 → NumPy calcola la dimensione
a.ravel() / a.flatten()
Appiattiscono l'array a una dimensione: ravel() restituisce una vista quando può, flatten() restituisce sempre una copia.
a.transpose() / a.T
Scambia gli assi; su una matrice 2D inverte righe e colonne.
np.concatenate([a, b], axis=0)
Unisce più array lungo un asse che esiste già in entrambi.
np.stack / vstack / hstack
stack crea un asse nuovo; vstack e hstack impilano rispettivamente in verticale e in orizzontale.
np.split(a, n) / hsplit / vsplit
Divide un array in n parti uguali lungo un asse.
np.expand_dims / np.squeeze
Aggiunge o rimuove assi di lunghezza 1: torna utile per far quadrare le forme nel broadcasting.
np.tile(a, reps)ripete l'intero array un certo numero di volte
np.repeat(a, n)ripete ogni singolo elemento n volte
np.roll(a, shift)trasla ciclicamente gli elementi lungo un asse
np.flip(a, axis)inverte l'ordine degli elementi lungo un asse
np.pad(a, width)aggiunge un bordo (di default zeri) intorno all'array

Operazioni matematiche

Le funzioni matematiche di NumPy lavorano elemento per elemento (elementwise) su interi array, senza bisogno di cicli espliciti.

+ - * / **
Operatori aritmetici standard, applicati elemento per elemento. Attenzione: * non è il prodotto matriciale.
np.sqrt(a) / np.exp(a) / np.log(a)
Radice quadrata, esponenziale e logaritmo naturale, elemento per elemento.
np.abs(a) / np.round(a, n)
Valore assoluto e arrotondamento a n cifre decimali.
np.floor(a) / np.ceil(a)
Arrotondamento verso il basso e verso l'alto.
np.clip(a, min, max)
Limita i valori dell'array entro l'intervallo [min, max].
np.clip([-2, 5, 12], 0, 10)
# array([0, 5, 10])
np.sin / np.cos / np.tan
Funzioni trigonometriche, argomenti espressi in radianti.
np.power(a, n) / np.mod(a, n)potenza e resto della divisione
np.sign(a)segno di ogni elemento: -1, 0 oppure 1
np.log2(a) / np.log10(a)logaritmi in base 2 e in base 10
np.maximum(a, b) / np.minimum(a, b)massimo/minimo elemento per elemento fra due array

Statistiche e aggregazioni

Riducono un array a un singolo valore, oppure a un array di dimensione inferiore, lungo uno o più assi.

a.sum(axis=None) / a.mean(axis=None)
Somma e media, sull'intero array oppure lungo un asse specifico.
m = np.arange(6).reshape(2, 3)
m.sum()        # 15, totale
m.sum(axis=0)  # [3, 5, 7]  → per colonna
m.sum(axis=1)  # [3, 12]    → per riga
a.std() / a.var()
Deviazione standard e varianza.
a.min/max() e a.argmin/argmax()
Valore minimo/massimo e indice a cui si trova.
np.median(a) / np.percentile(a, q)
Mediana e q-esimo percentile.
a.cumsum() / a.cumprod()
Somma e prodotto cumulativi elemento dopo elemento.
np.average(a, weights=w)media pesata
np.ptp(a)differenza tra massimo e minimo (peak to peak)
np.corrcoef(a, b)matrice di correlazione
np.histogram(a, bins)istogramma: conteggi per intervallo di valori

Algebra lineare — np.linalg

Il modulo np.linalg copre le operazioni matriciali classiche: prodotti, inversioni, autovalori, sistemi lineari.

a @ b / np.dot(a, b)
Prodotto matriciale. @ è l'operatore dedicato: ricorda che * resta elementwise.
np.linalg.inv(a)
Matrice inversa; richiede una matrice quadrata non singolare.
np.linalg.det(a)
Determinante della matrice.
np.linalg.solve(a, b)
Risolve il sistema lineare a·x = b: più stabile e più veloce di inv(a) @ b.
np.linalg.eig(a)
Autovalori e autovettori della matrice.
np.linalg.norm(a)
Norma del vettore o della matrice; di default la norma euclidea (L2).
np.linalg.matrix_rank(a)rango della matrice
np.linalg.qr(a) / np.linalg.svd(a)decomposizioni QR e SVD
np.trace(a)somma degli elementi sulla diagonale principale

Axis e broadcasting

Le due idee che, una volta capite bene, rendono NumPy intuitivo invece che criptico. Vale la pena fissarle prima di tutto il resto.

L'asse indica cosa collassa, non dove "scorre"

axis è la direzione lungo cui un'operazione riduce i dati. axis=0 collassa le righe, e il risultato ha un valore per ogni colonna; axis=1 collassa le colonne, e il risultato ha un valore per ogni riga. È l'errore più comune per chi inizia: pensare che axis=0 significhi "lungo le righe" nel senso di "risultato per riga".

Broadcasting: allineare forme diverse senza cicli

Quando le forme di due array non coincidono, NumPy prova ad allinearle automaticamente partendo dall'ultima dimensione: una coppia di dimensioni è compatibile se sono uguali, oppure se una delle due vale 1 (in quel caso viene "estesa" virtualmente). Non serve espandere manualmente gli array con un ciclo.

a = np.ones((3, 4))
b = np.array([1, 2, 3, 4])  # shape (4,)
a + b  # b viene applicato a ogni riga → shape (3, 4)

Confronti e logica

Confronti e operatori logici restituiscono array booleani: sono la base per il filtraggio e il mascheramento dei dati visto nella sezione sull'indicizzazione.

== != > < >= <=
Confronti applicati elemento per elemento: restituiscono un array di bool.
np.logical_and / or / not
Combinano condizioni booleane. and/or di Python non funzionano su array: servono queste.
a.any() / a.all()
True se almeno un elemento, o se tutti gli elementi, soddisfano la condizione.
np.isnan(a) / np.isinf(a)
Individuano valori NaN o infiniti: utile controllarli prima di un'aggregazione.
np.array_equal(a, b)
Confronta due interi array per uguaglianza (forma e valori).
np.isclose / np.allcloseconfronto con tolleranza, indispensabile quando si lavora con i float
& | ~versioni bitwise di and/or/not sugli array booleani — servono le parentesi: (a>1) & (a<5)

Ordinamento e ricerca

Ordinare e cercare valori, mantenendo traccia degli indici originali quando serve ricollegare il risultato ad altri array.

np.sort(a) / a.sort()
np.sort restituisce una copia ordinata; a.sort() ordina sul posto (in-place).
np.argsort(a)
Restituisce gli indici che ordinerebbero l'array: utile per ordinare più array in parallelo.
np.unique(a, return_counts=False)
Valori distinti in ordine crescente; con return_counts=True restituisce anche le occorrenze.
np.nonzero(a)
Indici degli elementi diversi da zero (spesso combinato con una condizione).
np.searchsorted(a, v)
Indice in cui inserire v per mantenere a ordinato.
np.partition(a, k)porziona l'array così che il k-esimo elemento sia al posto giusto: più veloce di un sort completo

Numeri casuali — np.random

Generazione di dati casuali per simulazioni, test e inizializzazione di modelli.

np.random.seed(n)
Fissa il seme casuale per rendere riproducibili i risultati.
np.random.rand(d0, d1, ...)
Numeri casuali uniformi in [0, 1), nella forma indicata.
np.random.randn(d0, d1, ...)
Numeri casuali da una normale standard: media 0, deviazione standard 1.
np.random.randint(low, high, size)
Interi casuali uniformi nell'intervallo [low, high).
np.random.choice(a, size, replace=True)
Estrae elementi casuali da un array, con o senza reinserimento.
np.random.shuffle(a)
Mescola l'array sul posto, lungo il primo asse.
np.random.permutation(a)come shuffle, ma restituisce una copia mescolata
np.random.normal(loc, scale, size)normale con media e deviazione standard a scelta
np.random.default_rng(seed)l'API moderna consigliata al posto delle funzioni legacy qui sopra

Note pratiche

Piccole cose che, sapute in anticipo, evitano la maggior parte dei bug più comuni con NumPy.

→

Vista o copia? Lo slicing restituisce quasi sempre una vista, cioè condivide la memoria con l'originale: modificarla modifica anche l'array di partenza. Usa a.copy() quando ti serve un array davvero indipendente.

→

Vettorizza invece di ciclare. Un ciclo for su un array NumPy è quasi sempre un segnale che manca un'operazione elementwise o una funzione di aggregazione pronta all'uso.

→

Il dtype si propaga. Mescolare interi e float in un'operazione fa scattare l'upcasting automatico a float; un array di soli interi con una divisione / diventa float senza preavviso.

→

NaN non è mai uguale a NaN. np.nan == np.nan restituisce False: per verificarlo serve np.isnan().

→

* non è il prodotto tra matrici. Per quello servono @ oppure np.dot(); * resta sempre elemento per elemento.

Guida pensata per lo studio personale. NumPy è un progetto open source: per i dettagli completi e i casi limite, la documentazione ufficiale resta il riferimento definitivo.
